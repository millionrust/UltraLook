# Studio North

A lightweight workspace for **small teams** who care about the details.

## Get started

```bash
npm install
npm run dev
```

## Inside the project

- **Components** — reusable pieces of the interface.
- **Public assets** — icons, images, and fonts.
- **Tests** — a few checks before every release.

> Build something small. Make it feel considered.
